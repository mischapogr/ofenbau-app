# Security policy

This is a demo/template project with no production backend of its own. If you
find a vulnerability in the code (for example in the Pages Functions under
`functions/`, the contact API in `server/`, or the build tooling), please report
it privately through GitHub's **"Report a vulnerability"** (Security → Advisories)
on this repository instead of opening a public issue.

You will get a response within a reasonable time, and the fix will be credited
in the changelog unless you prefer otherwise.

Please never include real credentials in reports; the repository contains no
usable secrets (see `docs/SECRETS.md`).
